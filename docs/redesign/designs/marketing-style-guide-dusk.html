Marketing design system

The Signal language.

Searchify's marketing surface runs on its own system — a warm, editorial, cinematic language built around one idea: the page itself behaves like an answer engine being audited. Dusk is the soft-dark theme: warm charcoal, cream ink, one electric gradient.

01

Principles

P1

Warm, never black

Dusk surfaces are warm charcoal (#262522 family) — a lighter, softer dark. Near-black is banned as a canvas; it only appears in recessed wells.

P2

One signal gradient

Violet → orchid → ember. It marks the moments that matter — the answer, the score, the CTA. Never decoration, never per-card hues.

P3

Type as the interface

Oversized tight-tracked display type carries the story; Georgia italic serif accents mark the human moments; mono carries every number.

P4

Motion with meaning

Every animation demonstrates the product — answers stream, mentions highlight, scores sweep. All CSS, all reduced-motion gated.

04

Signal usage

Discipline is what keeps it premium.

Signal on

  • The answer — hero headline accent word, mention highlights
  • The score — answer-score ring, proof-band numerals
  • One primary CTA per viewport (signal-deep fill)
  • The Pro tier rim and "most teams" tag
  • Hairline moments — kinetic divider fill, chapter numerals

    • Never

  • Card or section background fills — surfaces stay warm charcoal
  • Body copy, captions, or long paragraphs in gradient text
  • Different hue per card/feature (the v1 "candy" failure)
  • Pastel, low-saturation tints of the signal stops
  • More than one gradient moment in a single viewport
