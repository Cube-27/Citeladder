## Purpose

Use for "best", "top", "options", "examples", "ways", "ideas", or roundup content where a list is genuinely the most useful format.

## Structure

1. H1.
2. Short scope and selection methodology/criteria.
3. Optional quick-reference table.
4. One section per item.
5. Clear reason each item belongs on the list.
6. Best-for, trade-off, or differentiating note when context supports it.
7. How-to-choose section when readers need decision guidance.

## Tone

Practical and evidence-led.

## Craft rules

- Rank only when evidence supports ranking; otherwise use an unranked list.
- Apply reasonably consistent dimensions across items.
- Make item descriptions materially distinct.
- Avoid arbitrary numbering.
- Do not create external market options from thin air.
- Avoid unsupported "best overall" claims.
