## Purpose

Use when the main intent is "What is X?", "What does X mean?", or a closely related definitional query.

## Structure

1. H1 with the term.
2. Direct one- or two-sentence definition.
3. What it means / how it works.
4. Why it matters.
5. Concrete example when context supports one.
6. Related or commonly confused terms when helpful.
7. Optional concise FAQ.

## Tone

Clear, compact, educational.

## Craft rules

- Put the definition first.
- Define acronyms on first use.
- Keep the page focused.
- Clarify related concepts only when doing so prevents misunderstanding.
- Avoid circular dictionary-style definitions.
- Do not pad a simple definition into an unnecessarily long article.
