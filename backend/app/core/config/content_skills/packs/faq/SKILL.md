## Purpose

Use when the content is naturally expressed as discrete questions and answers.

Each answer should reduce uncertainty and make sense when read independently.

## Structure

1. Optional one-paragraph introduction naming the FAQ subject.
2. Natural-language question heading.
3. Direct answer in the first sentence.
4. Supporting explanation only when needed.
5. Group related questions if the set is large enough to benefit from grouping.

## Tone

Neutral, factual, clear.

## Craft rules

- Phrase questions the way a real user would ask them.
- Make each answer self-contained.
- Use exact brand/product names when ambiguity would otherwise exist.
- Avoid near-duplicate keyword variants.
- Use as many questions as the supplied task justifies; do not force a fixed count.
- Do not add FAQ solely for search-engine reasons.
