Paths are relative to `https://api.citeladder.com`. Reads need the `read` scope; each write lists its scope. Request and response fields are described in [openapi.json](https://api.citeladder.com/v1/openapi.json), which you can load into Postman, Insomnia or a client generator.

New fields and operations are added within `v1`; existing fields keep their meaning. See [REST API](/api/) for keys, pagination, idempotency and errors.
