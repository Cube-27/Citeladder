CiteLadder asked Claude Sonnet 5.5 20 buyer questions about cloud storage, three times each, in three conditions. From memory, Dropbox was the brand Claude named most often. When told to search first, pCloud took that place, and Microsoft and Apple dropped out of the top five. This page reports what Claude said. It is not a ranking of which service is best.

## What we asked Claude

This category is one of 20 in a study of 400 buyer questions. For cloud storage we wrote 20 prompts across five kinds of intent: best overall, a specific buyer or use case, budget or free, feature-led, and comparison shortlists.

Examples:

- "What's the best cloud storage service overall right now?"
- "Which cloud storage works best for photographers with huge RAW files?"
- "Which cloud storage services offer true end-to-end zero-knowledge encryption?"

Each prompt ran three times in each condition, which gives 60 answers per condition. The conditions were: from memory with no tools, with web search available, and told in the system prompt to search before answering. We used the Anthropic API at low effort and gave no current date. Another model listed the brands in each answer, and code counted them. API results can differ from the Claude apps.

## Brands Claude named from memory

Without tools, Claude named 57 distinct brands across 60 answers, an average of 7.2 per answer. The top three brands made up 26% of all mentions, so the field was fairly spread out.

- **Dropbox** appeared in 68% of answers and was named in every run for 12 prompts.
- **Microsoft** appeared in 62%.
- **Sync.com** appeared in 55%.
- **Google** appeared in 53%. It was named first 22 times, more than any other brand, with an average position of 1.9.
- **Apple** appeared in 48%.

Backblaze (40%), Proton (37%), pCloud (35%) and Tresorit (33%) followed. Google Drive was also counted on its own at 20%, separate from Google.

Run agreement was 62%. Claude gave a fairly similar set of brands when asked the same question again, but not an identical one.

## How often Claude searched when it could

With web search available but not required, Claude searched in only 6 of 60 answers, for 18 searches in total. Most answers still came from memory.

The results looked close to the no-tools condition. Dropbox and Microsoft each appeared in 70% of answers, Google in 68% and Sync.com in 60%. Microsoft was named in every run for 12 prompts. For this category, having search on hand did little to change which brands Claude named.

## What changed when Claude was told to search

When the system prompt told Claude to search first, it searched in all 60 answers and ran 249 searches. It named fewer brands: 47 distinct brands, an average of 5.9 per answer. The top three took 31% of mentions. Run agreement fell to 53%.

Dropbox, Sync.com and Google stayed in the top five. Two brands left it:

- **Microsoft** went from 62% from memory to 30%.
- **Apple** went from 48% from memory to 23%.

Two brands entered it:

- **pCloud** went from 35% from memory to 77%, and was named first 12 times.
- **Internxt** went from 15% from memory to 38%.

The leader changed from Dropbox to pCloud. Dropbox still appeared in 57% of searched answers, and Sync.com in 50%. None of the 60 searched answers included inline citations.

## What Claude searched for

Claude's queries were short and often focused on price or comparisons. 48% contained the word "best". Examples:

- "best cloud storage services 2025 comparison pricing"
- "cheapest cloud storage 2TB 2025 price comparison"
- "Backblaze B2 price per TB month 2026"

Some queries named several brands at once, such as "cloud storage sync speed comparison Dropbox Google Drive OneDrive pCloud Sync.com". Others looked up smaller services directly, such as "Koofr OR Hetzner storage box OR Internxt 2TB price per year".

42% of queries included a year. 2025 appeared in 104 queries and 2026 in 5. We gave no current date, so the year in a query was Claude's own assumption.

## Which sites the searches returned

A small set of review and comparison sites came back again and again. cloudwards.net was returned for 58 of the 60 searched answers (97%). techradar.com came back for 43 (72%). tomsguide.com and gizmodo.com each came back for 31 (52%), and experte.com for 30 (50%).

toolradar.com and en.wikipedia.org each appeared for 24 answers (40%). allcloudhub.com appeared for 20 and fast.io for 17.

One vendor domain made the list. blog.internxt.com was returned for 23 answers (38%). Internxt itself appeared in 38% of searched answers, up from 15% from memory. This study does not show that one caused the other, but the two moved in the same condition.

## What a cloud storage brand can take from this

Claude's memory and Claude's search results tell different stories in this category. A brand that does well from memory can drop by half when Claude searches, as Microsoft and Apple did. A brand with a middling memory share can lead once search is on, as pCloud did.

Some practical points:

- **Know the review sites.** cloudwards.net came back for almost every searched answer, and techradar.com for most. How your service is covered there shapes what Claude reads.
- **Publish clear pricing.** Many queries asked for a price per TB or a 2TB price per year. Plain, current pricing pages give Claude something to find.
- **Your own content can be returned.** blog.internxt.com showed up in a large share of searches.
- **Keep dates current.** Most dated queries used 2025, a few used 2026. Pages with an old year in the title may match fewer queries.
- **Measure both modes.** Check how Claude names you from memory and when it searches. CiteLadder tracks both.

## Frequently asked questions

### Which cloud storage brand did Claude name most often?

From memory, Dropbox appeared in 68% of answers. When told to search first, pCloud appeared in 77%. This shows what Claude said in this study, not which service is best.

### Does Claude search the web for cloud storage questions on its own?

Rarely in this study. With search available but not required, Claude searched in 6 of 60 answers. It searched in all 60 only when the system prompt told it to.

### Which websites did Claude's searches return most often?

cloudwards.net was returned for 97% of searched answers, techradar.com for 72%, and tomsguide.com and gizmodo.com for 52% each. blog.internxt.com was the one vendor domain in the top ten, at 38%.

### Will the Claude app give the same answers?

Not necessarily. These results come from the Anthropic API at low effort with no current date given. The Claude apps can use different settings and tools, so their answers can differ.
